# Contributing

Contributions are welcome when they remain provider-neutral, reproducible, and
public-safe.

- Use only Python standard-library runtime and test dependencies.
- Add synthetic or unquestionably public fixtures with expected results.
- Preserve exact evidence labels and the four baseline architecture names.
- Keep scientific, citation, security, canonical, and release authority with
  the frontier reviewer.
- Never add automatic code application, credentials, private URLs, raw model
  records, model weights, unpublished data, or unsupported performance claims.
- Run the four offline commands in the project directive and report failures
  accurately.

Changes require deterministic QA followed by human semantic review. A passing
synthetic benchmark is not scientific or real-model evidence.
