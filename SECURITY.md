# Security policy

This research prototype is not a secure production agent. Do not place
credentials, authentication headers, unpublished research, private paths, raw
prompts, raw responses, model files, or personal data in issues, fixtures,
logs, bundles, or pull requests.

The public MVP is fail-closed for automatic application: `automatic_apply` is
always `false`. A security report should describe the affected public file and
reproducible offline steps without including secrets. Security review does not
authorize a release or a provider connection.

When the repository is published, use GitHub's private vulnerability-reporting
channel in the Security tab if it is enabled. Do not place a sensitive report
in a public issue.
