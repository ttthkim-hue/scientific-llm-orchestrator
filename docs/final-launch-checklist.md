# Final launch checklist

This checklist is intentionally open. A deterministic scan is not final
publication approval.

- [ ] Human semantic review of every manifest entry.
- [ ] Confirm code and fixture license/attribution status.
- [ ] Confirm no private source, data, path, URL, credential, or model blob.
- [ ] Re-run unit, static, synthetic, publication, diff, and fresh-clone QA.
- [ ] Verify actual-model evidence is labelled `not-run` unless independently
      measured on public fixtures.
- [ ] Review provider terms on the execution date before any provider call.
- [ ] Obtain separate approval for repository creation, push, merge, release,
      publication, promotion, and applications.
- [ ] Read back the final public artifact from its remote side if created.
