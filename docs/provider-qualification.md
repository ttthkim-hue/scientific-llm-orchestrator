# Provider qualification boundary

Provider qualification is intentionally **not-run** in this public MVP. The
example binding is dry-run only and stores no credentials. No provider ranking,
pricing, quota, eligibility, retention, training, or region claim is made.

Future qualification should use identical public/synthetic fixtures and record
the date of official terms review, provider/model identity, structured-output
fidelity, deterministic task quality, latency, retries, privacy suitability,
reproducibility, and fallback behavior. A temporary free allowance is not a
long-term architecture decision. Provider names belong in run metadata, not
in generic architecture semantics.
