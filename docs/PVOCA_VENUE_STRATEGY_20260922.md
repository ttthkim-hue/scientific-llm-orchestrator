- Shared ARR submission deadline: 2026-10-12 AoE.
- Meta-reviews: 2026-12-18.
- Commitment deadline: 2026-12-23.
- NAACL and COLING are selected only after ARR reviews/meta-review.

### ACL 2027
- ACL 2027 official site has not yet fixed its own final dates.
- ACL Rolling Review currently lists the final ARR submission window for ACL 2027 as January 2027.

This is the safer major-conference target if the October 2026 package is not scientifically complete.

### TMLR
- Rolling submission.
- Emphasizes technical correctness over subjective significance.
- Appropriate for rigorous positive or negative/null results when the experimental package is complete.

## P-VoCA submission decision

### Route 1 — unusually strong results completed before ARR 2026 October
Target the October 12 ARR cycle.

Required internal bar:
- preregistered v3 matrix complete,
- 2 task families,
- 2 Qwen scales,
- preferably Gemma 3 cross-family extension,
- conservative non-inferiority satisfied,
- >=10% positive-paper cost gain,
- calibration <=0.10,
- simple question-only and disagreement baselines beaten or clearly characterized,
- related-work audit updated,
- reproducibility receipts complete.

After reviews, select NAACL 2027 or COLING 2027 based on the final framing and review feedback.

### Route 2 — strong result but October package is rushed
Do not compress the science merely to hit October 12.

Use the January 2027 ARR cycle for ACL 2027 instead.

The project prioritizes:
- larger evidence,
- cross-family replication,
- correct statistics,
- strong ablations,
over an earlier deadline.

### Route 3 — methodologically complete but modest/negative result
Use TMLR rolling submission.

The paper framing becomes:
- characterization of heterogeneous cognitive-action value,
- limits of lightweight routing,
- rescue/harm analysis,
- calibrated negative or mixed findings,
- reproducible scientific inference-control benchmark protocol.

## Writing trigger

Do not start final claim wording from the 108-item pilot.

A manuscript skeleton may be prepared now, but:
- abstract conclusions,
- headline numbers,
- title strength,
- deployment claims,
must wait for preregistered v3 results.

## Current recommendation

Primary scheduling target:
1. Attempt to finish preregistered v3 evidence early enough to evaluate the 2026-10-12 ARR window.
2. Submit to that cycle only if the scientific package is genuinely complete.
3. Otherwise preserve quality and move to the January 2027 ARR cycle / ACL 2027.
4. Keep TMLR as the rigorous rolling path for a result that is scientifically useful but not sufficiently strong for the preferred conference framing.
