## Project title

Reliable and Resource-Efficient Frontier-Local LLM Orchestration for Scientific
Software Engineering

## Positioning

A materials researcher is evaluating reproducible scientific software,
simulation-mechanics, manuscript/figure, and parametric-CAD workflows rather
than training a foundation model. The public prototype keeps authority with a
frontier reviewer and validates bounded worker proposals deterministically.

## Research questions

1. Which verifiable workflow tasks can be delegated without reducing accepted
   quality?
2. How much hosted work can routing and deterministic validation displace?
3. What are the quality, latency, energy, and privacy trade-offs?
4. Can visual and parametric-CAD workers reduce iteration while preserving
   scientific authority?

## Public outputs and controls

Planned outputs are an open-source framework, synthetic/public benchmark,
sanitized reproducibility artifacts, provider-neutral scorecard, and future
technical report. Controls include authority flags, evidence labels, privacy
classes, no raw private data publication, no automatic release actions, and
separate human approval.

Resource quantities, institutional statements, data policy, and exact provider
terms require execution-date verification and user review before submission.
