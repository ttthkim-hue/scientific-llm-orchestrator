# Limitations

- No actual model, provider, API, visual runtime, CAD kernel, or external
  dataset is called.
- Synthetic arithmetic and label inventories do not establish model quality,
  scientific correctness, or practical cost.
- The dry-run adapter records routing only and does not emulate provider
  failures, tokenization, latency, energy, or privacy terms.
- The route policy is intentionally small and fail-closed; it is not a general
  task planner.
- The publication scan is deterministic pattern checking, not legal, security,
  licensing, or semantic review.
- Generated code is never applied automatically.
